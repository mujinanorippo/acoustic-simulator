# 材料データ

1材料1ファイルの JSON。形式は `shared/schema/material.schema.json`。

数値ごとに出典（名前・URL・確認日）と信頼度を必ず付ける。欠けているファイルは自動チェック（`tools/check_materials.py`）で不合格になる。

信頼度が「二次情報」「暫定」の値を計算に使った結果には、画面に「暫定値を含む」と表示する。
