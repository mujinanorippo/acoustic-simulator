## この確認で見つけて直したもの

1. 壁の計算（約 5.6 秒）の間、画面が固まって止められなかった → 別スレッド化、進み具合の表示、「中止」ボタン、計算中の二重実行防止
2. 画面に出す要約（帯域ごとの結果・二重壁共鳴・コインシデンス）の関数に単体テストが無かった → 追加
3. ブラウザがアイコン（favicon）を探して 404 エラーを出していた → 空のアイコンを指定
4. 照合用 Python の一部の関数がテストで実行されていなかった → 追加
