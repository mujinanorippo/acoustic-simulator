## この確認で見つけて直したもの

1. 壁の計算（約 5.6 秒）の間、画面が固まって止められなかった → 別スレッド化、進み具合の表示、「中止」ボタン、計算中の二重実行防止
2. 画面に出す要約（帯域ごとの結果・二重壁共鳴・コインシデンス）の関数に単体テストが無かった → 追加
3. ブラウザがアイコン（favicon）を探して 404 エラーを出していた → 空のアイコンを指定
4. 照合用 Python の一部の関数がテストで実行されていなかった → 追加
5. （材料の参考値を追加したあと）タブを切り替えても「壁の遮音」の参考表が消えなかった（hidden 属性が CSS の display に負けていた）→ 画面操作テストで見つけて修正

## 追加した機能（のりちゃんの要望 2026-10-23）

材料を選ぶと出典つきの参考値が入る（自分で書き換えると「参考値」の印が消える）、損失係数・臨界周波数×板厚・流れ抵抗の説明、面密度と流れ抵抗の参考表、開口部は壁と開口部の面積を入れるとその場で計算、残響時間は面ごとに材料（残響室法吸音率）を選んで6帯域で計算し、吸音率の基準の説明と参考表を表示。ヤング率の代わりに「臨界周波数×板厚」を使う理由：建材のヤング率はメーカーの公表値がほとんど見つからない一方、教科書の表に材料ごとの値があり、ポアソン比も要らないため。

## 実測との比較（単板の透過損失）

出典：神奈川県「（参考）建築材料の透過損失」（日本建築学会編『実務的騒音対策指針（第二版）』から）。オクターブ帯域 [dB]。計算は無限に広い板・拡散入射（0〜78°）・損失係数 0.01（暫定）。差 = 計算 − 実測。

| 材料                                | 125 Hz | 250 Hz | 500 Hz | 1 kHz | 2 kHz |
| ----------------------------------- | -----: | -----: | -----: | ----: | ----: |
| 板ガラス 3 mm                       |   −1.9 |   −1.4 |   +1.4 |  +1.2 |  +3.3 |
| 板ガラス 5 mm                       |   −0.9 |   −0.1 |   +0.7 |  +3.1 |  +1.6 |
| 板ガラス 8 mm                       |   −1.0 |   +0.9 |   +3.5 |  +6.4 |  −5.2 |
| せっこうボード 9（計算は 9.5 mm）   |   +2.3 |   +3.9 |   +2.7 |  +2.5 |  −0.6 |
| せっこうボード 12（計算は 12.5 mm） |   −0.6 |   +5.1 |   +3.9 |  +2.5 |   0.0 |

多くは ±4 dB 以内。いちばん大きいのは板ガラス 8 mm のコインシデンス付近（1〜2 kHz）で、損失係数を 0.03 にすると 2 kHz の差は −2.2 dB まで縮む（損失係数が暫定値であることの影響）。合板の密度は北米の合板の値（NRC CBD-239）。ラワン合板 12 mm は 125 Hz で実測が計算より 8 dB 高く、帯域の基準を超えるのでテストには入れていない。テスト（tmm-validation.test.js）では、帯域ごとに ±7 dB、平均 4 dB 以内であることを確かめる。
