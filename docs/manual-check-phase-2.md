# フェーズ2 手動確認チェックリスト

開発設計書「手動確認」：自動テストでは見られない操作感をのりちゃんが触って確かめる。全部 OK ならフェーズ2完了（`phase-2-done` タグ）。

## 部屋の形

- [ ] 開くとすぐ「部屋の形」タブで、6畳の部屋が青系の背景の3Dで出る
- [ ] マウスで回転・ズーム・平行移動ができる（左ドラッグ・ホイール・右ドラッグ）
- [ ] 「ブロック」で右隣にブロックがくっつき、容積が増える
- [ ] 「ブロック穴」で角に机の分の穴があく
- [ ] 「円柱」「円柱穴」が置ける（円柱穴は柱の分がくり抜かれる）
- [ ] 表の数字（mm）を変えて Enter すると、3Dがその場で変わる
- [ ] ブロックを離して置くと「部屋が分かれた（E-GEO-005）」が出て、元の形に戻る
- [ ] 0・マイナス・文字・全角数字を入れると理由が出て、元の値に戻る

## 開口部サーフェス

- [ ] 「ドア」「窓」「開口部」で、壁の上に色付きの面が貼られる（ドアは茶、窓は水色、開口部はオレンジ）
- [ ] 開口部を壁の外（部屋の中の位置）に動かすと「E-GEO-008」が出て元に戻る
- [ ] 同じ壁で開口部同士を重ねると「E-GEO-011」が出て元に戻る

## 保存・読込

- [ ] 「保存」で保存先を選ぶダイアログが出て、保存できる
- [ ] 保存先の選択をキャンセルしても何も変わらない
- [ ] 「新規作成」で6畳に戻り、「開く」で保存したファイルを開くと元の形に戻る
- [ ] 壊れたファイルや別のソフトの JSON を開くと理由が出て、今の部屋はそのまま
- [ ] Firefox で開くと「保存はダウンロードになります」と出て、保存するとダウンロードされる
