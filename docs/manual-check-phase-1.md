# フェーズ1 手動確認チェックリスト

開発設計書「手動確認」：自動テストでは見られない操作感をのりちゃんが触って確かめる。全部 OK ならフェーズ1完了（`phase-1-done` タグ）。

## 壁の遮音

- [ ] 画面を開くと4層（板・空気層・多孔質材・板）の入力例が入っている
- [ ] 「計算」を押すと、グラフと 50〜5000 Hz の表が出る
- [ ] 「二重壁の共鳴周波数の目安」が出て、グラフのへこみの位置とだいたい合う
- [ ] 板のヤング率を 0 以外（例 2.5）にすると「コインシデンス限界周波数」が出て、その付近でグラフがへこむ
- [ ] 層の追加・削除・↑↓の並べ替えができる
- [ ] 計算中に「計算中… ○ / 21 帯域」が出て、「中止」で止められる
- [ ] わざと間違える：空欄、0、マイナス、全角数字（１０）、文字（abc）、極端な値（99999）を入れて計算 → 理由つきの OK ダイアログが出て、画面が壊れない

## 開口部

- [ ] 壁 45 dB・開口率 1% で約 20 dB になる
- [ ] 壁の遮音を計算したあと「壁の遮音の結果に開口率を当てはめる」で、点線（壁だけ）と実線（開口部込み）のグラフが出る
- [ ] 開口率に 120 や -1 を入れると止まる

## 残響時間

- [ ] 6畳（3640×2730×2400 mm）の入力例で4つの式の結果が出る
- [ ] 吸音率を全部同じ値にすると、Eyring・Fitzroy・Arau-Puchades がほぼ同じ値になる
- [ ] 吸音率を全部 0 にすると「吸音がゼロのため残響時間が無限大」のダイアログが出る

## 見た目

- [ ] パソコンの画面を暗い表示（ダークモード）にしても読める
