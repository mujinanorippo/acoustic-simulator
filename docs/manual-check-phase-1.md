# フェーズ1 手動確認チェックリスト

開発設計書「手動確認」：自動テストでは見られない操作感をのりちゃんが触って確かめる。全部 OK ならフェーズ1完了（`phase-1-done` タグ）。

## 壁の遮音

- [ ] 画面を開くと4層（せっこうボード・空気層・グラスウール・せっこうボード）の入力例が入っていて、値の後ろに「（参考値）」が出る
- [ ] 「（参考値）」にマウスを乗せると出典が出る
- [ ] 材料を変えると値が入れ替わり、自分で書き換えた欄は「（参考値）」が消える
- [ ] 損失係数・臨界周波数×板厚・流れ抵抗の横に説明が出ている
- [ ] 枠の下に「主な遮音材の面密度」と「多孔質材の流れ抵抗」の参考表があり、出典のリンクが開ける
- [ ] 「計算」を押すと、グラフと 50〜5000 Hz の表が出る
- [ ] 「二重壁の共鳴周波数の目安」が出て、グラフのへこみの位置とだいたい合う
- [ ] せっこうボード 12.5mm で「コインシデンス限界周波数：3040 Hz」が出て、その付近でグラフがへこむ
- [ ] 層の追加・削除・↑↓の並べ替えができる
- [ ] 計算中に「計算中… ○ / 21 帯域」が出て、「中止」で止められる
- [ ] わざと間違える：空欄、0、マイナス、全角数字（１０）、文字（abc）、極端な値（99999）を入れて計算 → 理由つきの OK ダイアログが出て、画面が壊れない

## 開口部

- [ ] 壁 45 dB・壁の面積 9.9 m²・開口部 990 cm² で、ボタンを押さなくても開口率 1.00 % と約 20 dB が出る
- [ ] 壁の遮音を計算すると、開口部タブに点線（壁だけ）と実線（開口部込み）のグラフが自動で出る
- [ ] 開口部の面積を壁より大きくしたり文字を入れたりすると、理由が出る

## 残響時間

- [ ] 6畳（3640×2730×2400 mm）の入力例で、125〜4000 Hz の6帯域×4つの式の表が出る
- [ ] 面ごとに材料を選べて、「自分で入力」にすると吸音率の欄が入力できるようになる
- [ ] 全部「自分で入力」で同じ値にすると、Eyring・Fitzroy・Arau-Puchades がほぼ同じ値になる
- [ ] 全部「自分で入力」で 0 にすると「吸音がゼロのため残響時間が無限大」のダイアログが出る
- [ ] 吸音率の基準（残響室法吸音率）の説明と、材料ごとの参考表が出る
