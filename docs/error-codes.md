# エラー番号一覧

開発設計書「エラー処理方針」に従い、エラーには番号を付ける。計算コア（ブラウザ側 `web/src/core-acoustics/errors.js`、照合用 Python `tests/reference_py/errors.py`）は同じ番号を使う。

| 番号       | 意味                                                       | 画面での案内                                   |
| ---------- | ---------------------------------------------------------- | ---------------------------------------------- |
| E-CALC-001 | 長さ・面積・体積が正の有限値でない、または面が1つもない    | 寸法を正の数で入力する                         |
| E-CALC-002 | 吸音率・開口率などの比が 0〜1 の範囲外、または数値でない   | 0〜1（0〜100%）で入力する                      |
| E-CALC-003 | 吸音がゼロで残響時間が無限大になる                         | どこかの面に吸音を設定する                     |
| E-CALC-004 | 音速・密度・面密度・流れ抵抗などの物性値が正の有限値でない | 物性値を確認する                               |
| E-CALC-005 | 周波数が正の有限値でない                                   | 周波数を正の数で入力する                       |
| E-CALC-006 | Fitzroy・Arau-Puchades に必要な x・y・z 各方向の面がない   | 直方体の部屋で計算する                         |
| E-CALC-007 | 帯域番号が帯域表の範囲外                                   | 帯域表（50 Hz〜5000 Hz）の範囲で選ぶ           |
| E-CALC-008 | 積層が空、または使えない層の種類                           | 層の種類（空気層・多孔質材・板・有孔板）を選ぶ |
| E-CALC-009 | 計算途中の数値が扱える範囲を超えた                         | 層の厚さや周波数を見直す                       |
| E-CALC-010 | 入射角が 0 以上 90° 未満でない                             | 角度を見直す                                   |
| E-CALC-011 | 開口部の面積が壁の面積より大きい                           | 面積を見直す                                   |

## 形状（web/src/core-model/errors.js）

| 番号      | 意味                                                                        | 画面での案内                               |
| --------- | --------------------------------------------------------------------------- | ------------------------------------------ |
| E-GEO-001 | 寸法（大きさ・直径・長さ・開口部の幅）が 1 mm〜100 m の範囲外・数でない     | 寸法を見直す                               |
| E-GEO-002 | 位置・向きが数でない、±1000 m を超える、x・y・z 以外                        | 位置と向きを見直す                         |
| E-GEO-003 | 形の種類が分からない                                                        | ブロック・ブロック穴・円柱・円柱穴から選ぶ |
| E-GEO-004 | 最初の形が穴                                                                | 最初はブロックか円柱を置く                 |
| E-GEO-005 | 部屋が2つ以上に分かれている（離れている・辺や点だけで触れている・穴で分断） | 面で接するように置く                       |
| E-GEO-006 | 形が1つもない、または穴で部屋が全部なくなった                               | 形を置く・穴を見直す                       |
| E-GEO-007 | 形が200個、開口部が100個を超えた                                            | 形をまとめる                               |
| E-GEO-008 | 開口部が部屋の壁・床・天井の面の上にない                                    | 開口部を面の上に置く                       |
| E-GEO-009 | 開口部の種類が分からない                                                    | ドア・窓・開口部から選ぶ                   |
| E-GEO-010 | 形・開口部の番号（id）が空か重複している                                    | ファイルが壊れている可能性。保存し直す     |
| E-GEO-011 | 同じ面の開口部同士が重なっている（辺で接するだけなら可）                    | 開口部の位置をずらす                       |

## ファイル（web/src/io/errors.js）

読めないファイルは読み込まず、今開いているデータは消さない。

| 番号     | 意味                                                                       | 画面での案内                           |
| -------- | -------------------------------------------------------------------------- | -------------------------------------- |
| E-IO-001 | ファイルが空                                                               | 別のファイルを選ぶ                     |
| E-IO-002 | JSON として読めない（壊れている）                                          | 別のファイルを選ぶ・保存し直す         |
| E-IO-003 | このソフトのプロジェクトファイルではない（他のソフトのファイル）           | 正しいファイルを選ぶ                   |
| E-IO-004 | 新しい版で作られたファイル                                                 | ソフトを新しくしてから開く             |
| E-IO-005 | ファイルが 10 MB を超える                                                  | 正しいファイルを選ぶ                   |
| E-IO-006 | 中身が正しくない（版・単位・項目・形のデータ。形のエラー番号も一緒に表示） | ファイルが壊れている可能性。保存し直す |
| E-IO-007 | 保存できなかった（保存先が書き込めない など）                              | 別の保存先を選ぶ                       |
